void AdcRegisterCallback ( void   userAdcCallbackvoid)

Register a callback function, which will be called when a conversion is complete.

Parameters
userAdcCallbackname of the callback function

First register the callback, then enable the interrupt via AdcEnableInterrupts().

Note: The HAL does implement an Interrupt Service Routine (ISR) for the ADC interrupts 22. So the user may use a normal function instead of an ISR. If the user wants to provide his own ISR, he/she should insert #define USER_ADC_ISR before line #include "HAL.h"
