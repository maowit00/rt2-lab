Program Flash memory.

Parameters
flashBlocknumber of the Flash block 0...3
pagenumber of memory page
startAddressstartAddress
datadata to be programmed
dataLengthlength of data in words (1 word = 2 byte = 16 bit)
Returns
0 for success, !=0 indicating failure

Note 1: Only erased memory can be programmed, so use MemFlashRomSectorErase() before.

Note 2: Program data and dataLength are in Word rather than Byte, because the HCS12 controller can only reprogram 16bit values.

Note 3: Memory in the current Flash block from which the program is executing cannot be reprogrammed!

uint8 MemSetPage ( uint8  newPage)

Change Flash ROM memory page.

This function changes the Flash ROM block, which is mapped into address range 0x4000-0x7FFF. The DP256 has 16 blocks of 16KB, the DP512 has 32 blocks of 16KB each.

Parameters
newPagenumber of memory page to set, range 0x30 ... 0x3D for DP256
Returns
number of previous page

Note: 0x3E is a mirror of memory locations 0x4000-0xBFFF, 0x3F is a mirror of locations 0xC000-0xFFFF.

To move a function to a mapped page, declare the function as:
#pragma CODE_SEG OTHER_ROM
void __far functionName(...) { ...}
#pragma CODE_SEG_DEFAULT
When calling the function, the compiler will automatically generate the required code to change the PPAGE register.

To move data constant to a mapped page, declare the constant as:
#pragma DATA_SEG OTHER_ROM
const int x = ...;
#pragma DATA_SEG OTHER_ROM
Before you access this constant, you have to switch the memory page manually using MemSetPage().

OTHER_ROM must have been declared in the .prm locater configuration file.
