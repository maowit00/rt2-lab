void WdgInit ( uint8  x)

Initialize Watchdog.

Parameters
x0...7 watchdog time period select (number of OSCCLK cylces)

Note: Once you start the watchdog, you must periodically call WdgRetrigger() within the watchdog time period. Otherwise the CPU will reset. There is no way to stop the watchdog, once initialized.
